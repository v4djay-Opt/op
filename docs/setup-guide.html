1 Generate a secret key

Required 2 minutes · On your Mac

This password lets WordPress tell the website "content changed, refresh now". Both sides must use the same value.

openssl rand -hex 32

2 Install the WordPress plugin

Required 5 minutes · Hostinger hPanel → File Manager

The plugin file is in your project at:

opweb26/wordpress/mu-plugins/optimax-headless.php
“Must-use” plugins are always on and can't be disabled by accident from the Plugins screen — that's why we use this folder.

3 Edit wp-config.php

Required 5 minutes · File Manager

define( 'OPTIMAX_FRONTEND_URL', 'https://optimaxstudio.com' );
define( 'OPTIMAX_REVALIDATE_SECRET', 'PASTE-YOUR-SECRET-HERE' );
From now on, visiting blog.optimaxstudio.com in a browser will redirect to optimaxstudio.com. That's intended — editors use blog.optimaxstudio.com/wp-admin, which still works.

4 Clean up WordPress

Required 10 minutes · wp-admin

You do not need Yoast, Rank Math or ACF. SEO title, meta description and all custom fields are in the “Optimax fields” box under the editor.

5 Deploy the website code

Required · Your usual deploy process

The code changes are on your Mac but not committed or deployed yet.

git add -A
git commit -m "Switch CMS to headless WordPress, fix canonical domain and SEO"
git push

6 Set environment variables

Required 5 minutes · hPanel → your Node.js app settings (and your local .env.local)

NameValue
NEXT_PUBLIC_SITE_URLhttps://optimaxstudio.com (no www, no trailing slash)
WORDPRESS_URLhttps://blog.optimaxstudio.com
WORDPRESS_REVALIDATE_SECRETYour secret from Step 1 — identical to wp-config.php

7 Test everything works

Required 10 minutes · Browser + Terminal

Quick check from Terminal (each line should show 301 or 308):

curl -sI https://www.optimaxstudio.com/ | head -1
curl -sI https://optimaxstudio.com/services/seo | head -1
curl -sI https://blog.optimaxstudio.com/ | head -1
If the live-update test doesn't work: the secret in wp-config.php and WORDPRESS_REVALIDATE_SECRET don't match exactly, or the app wasn't restarted. Content still updates automatically within ~5 minutes either way.
